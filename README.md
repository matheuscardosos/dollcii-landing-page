# Dollcii

Landing page moderna e animada para a marca Dollcii, de picoles e sorvetes artesanais.

Feita por **math.scs**

## Stack

- React + Tailwind CSS
- Framer Motion (animacoes)
- Three.js / React Three Fiber (cena 3D do hero)
- Shadcn UI

## Como rodar

```bash
cd frontend
npm install
npm start
```

O app abre em `http://localhost:3000`.
